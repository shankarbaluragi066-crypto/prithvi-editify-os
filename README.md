# Prithvi Editify — Freelance Creative Studio & Client CRM

Full-stack freelance creative studio website, client portal, project management, media library, and INR invoicing CRM for **Prithvi Editify** (Owner: **Shankar Baluragi**).

Built with **React 19, TypeScript, Vite, Tailwind CSS, React Router, React Hook Form, Zod, and Supabase (PostgreSQL, Row Level Security, Auth & Storage)**.

---

## 1. GitHub Pages Deployment (`prithvi-editify`)

This repository is configured for deployment to:
**`https://shankarbaluragi066-crypto.github.io/prithvi-editify/`**

### Why "Deploy from branch (`main` / root)" Does Not Work for Vite
A Vite + TypeScript + React project cannot be served directly from the uncompiled root of the `main` branch because browsers cannot natively execute `.tsx` files (`src/main.tsx`) or bare NPM imports. GitHub Pages must serve the compiled **`dist/`** output generated by `npm run build`.

### Correct GitHub Pages Setup (GitHub Actions)
1. Commit and push the updated project files (including `.github/workflows/deploy.yml`, `vite.config.ts`, `package.json`, `index.html`, and `src/`).
2. In your GitHub repository (`shankarbaluragi066-crypto/prithvi-editify`), go to **Settings → Pages**.
3. Under **Build and deployment → Source**, change from *Deploy from a branch* to **GitHub Actions**.
4. In **Settings → Secrets and variables → Actions**, add your public Supabase client keys (under **Repository secrets** or **Variables**):
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_PUBLISHABLE_KEY`
5. Every push to `main` (or manual run in the **Actions** tab) automatically builds `./dist` with `base: '/prithvi-editify/'`, generates `dist/404.html` for React Router SPA refresh/direct-navigation support, and deploys to GitHub Pages.

## 2. Local Development & Production Build

```bash
# Install dependencies
npm install

# Start development server (port 3000)
npm run dev

# Type-check TypeScript
npm run lint

# Build production bundle into ./dist (for /prithvi-editify/)
npm run build
```

## 3. Supabase Database & Storage Setup

1. Create a Supabase project and copy your **Project URL** (`VITE_SUPABASE_URL`) and **Anon / Publishable Key** (`VITE_SUPABASE_PUBLISHABLE_KEY`) into `.env`.
2. Open the **Supabase SQL Editor** and run:
   `supabase/migrations/20261018000000_prithvi_editify_schema_and_rls.sql`
3. Sign in at `/login` with **`shankarbaluragi066@gmail.com`** to access the Admin Console (`/admin`).
